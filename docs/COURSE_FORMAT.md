# Формат курса (JSON)

```json
{
  "id": "ru-basic",                 // уникальный id курса (латиница, без пробелов)
  "title": "Русский: базовый курс", // название на вкладке
  "layout": "ru",                   // раскладка: "ru" (ЙЦУКЕН) или "en" (QWERTY)
  "criteria": { "minCpm": 100, "minAccuracy": 96 },   // зачёт по умолчанию
  "parts": [
    {
      "title": "Домашний ряд",      // ступень: заголовок группы в списке уроков
      "lessons": [
        {
          "id": "ru-01",            // уникальный id урока в курсе (по нему хранится прогресс!)
          "title": "Клавиши Ф Ы В А",
          "newKeys": "ФЫВА",        // справочно
          "intro": "Новые клавиши: Ф — левый мизинец; ...",   // описание над клавиатурой
          "exercises": [            // строки; урок = все строки подряд, статистика общая
            "фф ффф фф ффф ыы ыыы ыы ыыы вв ввв вв ввв аа ааа аа ааа",
            "фы ыф фв вф ..."
          ],
          "minCpm": 60,             // необязательно: порог именно для этого урока
          "minAccuracy": 95
        }
      ]
    }
  ]
}
```

Правила:

* Строка упражнения может содержать только символы, которые есть на выбранной раскладке (буквы обоих
  регистров, цифры, знаки, пробел). Загрузчик проверяет id/раскладку/пустые упражнения; полная проверка
  «набираемости» — `CourseLoader.CheckTypeable` (её вызывает `tools/SelfCheck`).
* Не меняйте `id` уроков, если уже есть прогресс: он привязан к `курс/урок`.
* Длина строки: оптимально 40–70 знаков (текст прокручивается по горизонтали, длинные тоже работают).
* Комментарии `//` и «хвостовые» запятые в JSON допускаются загрузчиком.
