# DexterType 2.0 — клавиатурный тренажёр (WPF, .NET 8)

Внешний вид и навигация — в духе **Stamina** (список уроков слева, строка с текстом, экранная клавиатура
с цветными зонами пальцев, показатели скорости и точности, итог урока).
Структура уроков — по принципу **«Соло на клавиатуре»**: ступени → уроки с 1–4 новыми клавишами →
несколько коротких упражнений на урок (ритм, пары, слоги, слова, предложения), зачёт по скорости и точности.
**Звуки при ошибках** синтезируются в памяти (внешние файлы не нужны) и различаются по типу ошибки.

## Что внутри

```
DexterType.slnx
Dexter.Core/            ядро без WPF (net8.0): курсы, раскладки, движок набора, прогресс, синтез звуков
DexterType/             WPF-приложение: окна, темы, экранная клавиатура, воспроизведение звука
DexterType/Courses/     ru-basic.json, en-basic.json (сгенерированы, копируются рядом с exe)
tools/generate_courses.py   генератор курсов из словарей tools/courses/*.txt (+ проверка данных)
tools/SelfCheck/        консольная самопроверка ядра и курсов (запускается и на Linux/macOS)
PROMPT.md               готовый промпт для ИИ-агента: как развивать проект дальше
docs/COURSE_FORMAT.md   формат JSON-курса
```

## Как поставить в репозиторий

1. В репозитории `DexterTypeWpf` удалите старые файлы из корня (их заменяет новая структура):
   `App.xaml`, `App.xaml.cs`, `MainWindow.xaml`, `MainWindow.xaml.cs`, `SettingsWindow.xaml`,
   `SettingsWindow.xaml.cs`, `TrainerEngine.cs`, `HistoryStore.cs`, `Layouts.cs`, `IconGenerator.cs`,
   `DexterType.csproj`, `DexterType.slnx`.
2. Распакуйте архив в корень репозитория (папки `Dexter.Core`, `DexterType`, `tools`, `docs` и файл `DexterType.slnx`).
3. Запуск: `dotnet run --project DexterType` (или откройте `DexterType.slnx`; формат `.slnx` требует
   .NET SDK 9.0.200+ либо свежую Visual Studio 2022 17.14+. С .NET 8 SDK используйте `dotnet run --project ...`).
4. Проверка ядра и курсов: `dotnet run --project tools/SelfCheck`.
5. Пересборка курсов после правки словарей: `python tools/generate_courses.py` (`--check` — только проверить).

Старые файлы данных (`history.json`, `music.txt`, `music_on.txt`) новая версия не читает. Настройки теперь в
`%AppData%\DexterType\settings.json`, прогресс — в `progress.json`.

## Управление

| Клавиша | Действие |
|---|---|
| Esc | начать урок заново |
| Enter | на итоговой карточке: следующий урок (если зачтён) или повтор |
| Ctrl+← / Ctrl+→ | предыдущий / следующий урок |
| F2 / F7 | настройки / статистика |
| клик по уроку слева | перейти к уроку (✓ зачтён, ◐ в процессе, ○ новый, 🔒 закрыт) |

Зачёт урока: скорость (зн/мин) и точность (%) не ниже порогов урока. Пороги заданы в JSON-курсе
(у каждого урока свои, значения по умолчанию — в `criteria` курса).

## Звуки ошибок

| Ситуация | Звук (набор «Классический») |
|---|---|
| не та клавиша | короткий грубый гудок «бззт» |
| нужна буква другого регистра (Shift / Caps Lock) | два коротких тона; подсказка «Включён Caps Lock» |
| символ не из раскладки курса (например, латиница в русском уроке) | нисходящий свист; подсказка «Переключите раскладку» |
| упражнение закончено / урок зачтён / не зачтён | мягкий тон / восходящее арпеджио / нисходящая фраза |

Наборов четыре (классический, мягкий, щелчок, писк), громкость и «прослушать» — в настройках (F2).
Воспроизведение через `winmm PlaySound` из памяти: низкая задержка, быстрые повторы не накапливаются.

## Свои курсы

Положите JSON (формат в `docs/COURSE_FORMAT.md`) в `%AppData%\DexterType\courses\` — он появится
вкладкой в верхней панели. Курсы со встроенными `id` игнорируются (приоритет у папки рядом с exe).

## Что проверено, а что нет

Проверено автоматически (Linux, .NET 8 SDK): сборка `Dexter.Core`; `tools/SelfCheck` — раскладки и Shift-логика,
все 50 уроков (26 русских + 24 английских) набираются на своей раскладке и зачитываются при идеальном
проходе, классификация ошибок, 24 звука (4 набора × 6) — корректный WAV, сохранение прогресса и настроек,
устойчивость к повреждённому JSON; генератор курсов проверяет, что в каждом упражнении только уже изученные клавиши.

**Не проверено:** сборка и запуск WPF-части (`DexterType/`) — в среде разработки нет Windows-таргетинга.
Код прошёл только синтаксический разбор Roslyn (без ошибок синтаксиса), поэтому при первой сборке возможны
мелкие ошибки компиляции или вёрстки. Если они появятся — пришлите вывод `dotnet build`, поправим.
Это же относится к визуальной «похожести на Stamina»: она сделана по памяти об интерфейсе, не по скриншотам.

## Что не сделано (идеи на потом)

Изображения рук поверх клавиатуры, редактор уроков в интерфейсе, профили пользователей, режим «свой текст»,
английский курс с более богатым словарём, экспорт статистики. Подробности — в `PROMPT.md`.
