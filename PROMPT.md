# Промпт для ИИ-агента: развитие DexterType

Скопируйте всё ниже линии в чат агента (Claude Code, Hermes и т. п.), находясь в корне репозитория `DexterTypeWpf`.

---

## Роль и контекст

Ты — старший C#/WPF-разработчик. Работаешь над **DexterType** — клавиатурным тренажёром для Windows
(.NET 8, WPF). Репозиторий уже содержит рабочую структуру версии 2.0. Твоя задача — развивать её, не ломая
границы между слоями.

### Цели продукта

1. **Внешний вид и навигация — как в Stamina:** слева список уроков со статусами, сверху панель курсов и кнопок,
   по центру строка с прокручиваемым текстом, ниже экранная клавиатура с цветными зонами пальцев и подсказкой
   «какой палец», сверху показатели (скорость, точность, ошибки, время), итоговая карточка урока.
2. **Структура уроков — как в «Соло на клавиатуре»:** ступени → уроки; в каждом уроке 1–4 новые клавиши;
   внутри урока несколько коротких упражнений (ритм, пары, слоги, слова, предложения); строгие пороги зачёта.
   Содержимое курсов пишется самостоятельно, тексты оригинальных курсов не копируются.
3. **Звуки при ошибках:** характерные, различающиеся по типу ошибки (неверная клавиша, регистр, раскладка),
   синтезируются в коде, без внешних аудиофайлов.

### Архитектура (границу слоёв сохранять!)

* `Dexter.Core` (net8.0, **без ссылок на WPF**): модели курса (`Course/Part/Lesson/Criteria`), `CourseLoader`,
  раскладки и пальцы (`KeyboardLayoutDef`, `KeyboardLayouts`), движок `TypingSession`, хранилища
  (`ProgressStore`, `SettingsStore`), синтез звуков `SoundSynth`. Вся логика, которую можно проверить без UI,
  живёт здесь.
* `DexterType` (net8.0-windows, WPF): только представление и платформенные вещи — окна, темы (`Theming/Themes.cs`),
  `KeyboardView`, `SoundService` (winmm `PlaySound`), `MusicService`.
* Курсы — данные (JSON в `DexterType/Courses/`), а не код. Генерируются `tools/generate_courses.py`
  из словарей `tools/courses/*.txt`.
* `tools/SelfCheck` — консольная самопроверка ядра и курсов. Должна проходить всегда.

### Правила работы

* Язык интерфейса и комментариев — русский. Код — C# 12, `Nullable` включён, без лишних зависимостей NuGet.
* Не добавляй WPF-типы в `Dexter.Core`. Не клади логику зачёта, подсчёта точности и классификации ошибок во view.
* Все цвета — через ресурсы темы (`DynamicResource ThemeXxx`, `ColorPinky…`); новые цвета добавляй в `ThemeDef` и `Themes.Apply`.
* Формат хранения прогресса: ключ `курс/урок`; **не меняй `id` существующих уроков** — потеряется прогресс.
* Перед каждым коммитом: `dotnet build` (все проекты), `dotnet run --project tools/SelfCheck`,
  `python tools/generate_courses.py --check`. Если меняешь курс, правь словари/генератор, а не JSON руками,
  затем пересобирай JSON.
* Если что-то не можешь проверить (например, нет Windows) — прямо скажи, что именно не проверено.

## Что уже сделано (v2.0)

* Раскладки RU/EN с пальцами, Shift по противоположной руке, поиск символа `Find(char)`.
* Курсы `ru-basic` (26 уроков) и `en-basic` (24 урока): домашний/верхний/нижний ряд, заглавные (Shift),
  цифры по пальцам, знаки препинания, тексты. Критерии зачёта растут по ходу курса.
* `TypingSession`: несколько упражнений подряд, общая статистика, ошибки не двигают курсор,
  исходы `Correct/WrongKey/CaseMismatch/WrongLayout/Ignored`, точность округляется вниз.
* Прогресс по урокам, журнал попыток (последние 500), топ «проблемных» символов, настройки.
* Окна: главное, настройки (темы, звук, музыка, последовательное открытие уроков), статистика (график, таблица).
* 4 набора звуков × 6 событий; подсказки «Caps Lock» и «Переключите раскладку».

## Задачи (по приоритету)

1. **Собрать WPF-проект под Windows и исправить ошибки компиляции/вёрстки.** Код WPF-части писался без
   компиляции. После сборки пройди все окна и сверь поведение со списком выше.
2. **Руки на экранной клавиатуре** (как в Stamina): векторные кисти левой и правой руки под клавиатурой,
   подсвечивается палец, который должен нажать клавишу (`KeyDef.Finger`, `KeyHit.ShiftKey` для Shift).
   Реализовать как отдельный контрол рядом с `KeyboardView`, переключатель в настройках (`AppSettings.ShowHands`).
3. **Сверка структуры с «Соло на клавиатуре».** Структура курса сейчас — разумное приближение, а не копия.
   Если у пользователя есть оригинальная последовательность уроков, поменяй порядок клавиш в `LANGS`
   (`tools/generate_courses.py`), сохранив проверку «только изученные символы».
4. **Режим «Свой текст»**: пользователь вставляет текст, он нарезается на упражнения по ≤ 70 знаков;
   проверка набираемости на раскладке (`CourseLoader.CheckTypeable`-логика), статистика отдельно.
5. **Редактор порогов зачёта** в настройках (множитель строгости для всего курса: 0.7 / 1.0 / 1.2).
6. **Профили пользователей** (отдельные `progress.json` и `settings.json` по профилю).
7. **Тесты:** перенести проверки из `tools/SelfCheck` в xUnit-проект `Dexter.Core.Tests`, добавить тесты
   на `ProgressStore.TopMistakes`, на обрезку журнала попыток и на генератор (детерминированность по seed).

## Критерии приёмки

* `dotnet build` проходит без предупреждений уровня error; SelfCheck — «Все проверки пройдены».
* В любом уроке: ошибка не двигает курсор, звучит звук нужного типа, строка мигает красным, подсказка корректна.
* Закрытие и повторный запуск сохраняют тему, настройки звука, последний урок, прогресс.
* Смена темы мгновенно перекрашивает окно, список уроков и клавиатуру (без перезапуска).
* Повреждённый `progress.json`/`settings.json` не роняет приложение (копия сохраняется как `.broken`).
